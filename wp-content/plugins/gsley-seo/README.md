# GSLEY SEO & AI-Search (plugin)

The SEO / AI-search layer (phase1-handoff.md §10 step 6). Kept in a **separate
plugin** so redirects, schema, and the sitemap survive theme changes.

## What it does

- **JSON-LD schema** (`includes/schema.php`, on `wp_head`) per the foundation §4
  map: `Organization` + `WebSite` (with `SearchAction`) site-wide; then per page
  type — `Person` (About), `Service` + `OfferCatalog` (each service page),
  `CollectionPage` + `ItemList` (services index, pillar hubs, tools hub),
  `SoftwareApplication` + `HowTo` (each tool), `ContactPage` (Contact), `WebPage`
  (legal), and `BreadcrumbList` on every inner page. `FAQPage` is emitted from
  the **real on-page Q&A** — the homepage FAQ and any service/tool page's
  `core/details` blocks are parsed, so the schema can't drift from the content.
- **Open Graph + Twitter + canonical + meta description** (`includes/meta.php`)
  on every page, wiring the per-page **OG image** (`/assets/og/<slug>.png`,
  bundled with the plugin; base URL filterable via `gsley_seo_og_base`).
- **sitemap.xml** (`includes/files.php`) — all 36 built URLs with handoff §5
  priorities (home 1.0; hubs/tools 0.8; services/tools 0.7; legal 0.3).
  Redirected and unbuilt URLs are excluded. Served at `/sitemap.xml`.
- **robots.txt** — allows search **and** the named AI crawlers (GPTBot,
  ClaudeBot, PerplexityBot) and points to the sitemap. Respects the
  "discourage search engines" setting on staging.
- **llms.txt** — the bundled manifest served at `/llms.txt`.
- **301 redirects** (`includes/redirects.php`) — handoff §4 + foundation §2:
  `/diagnostic` → `/tools/growth-diagnostic`,
  `/services/market/media-management` → `…/institutional-brand-and-reputation#media-management`,
  `/services/digital/business-development` → `/services/market/strategic-partnerships`.
  `social-media-management` is **not** redirected — it is a separate page.

## OG images

Generated by `generate-og-images.py` at the repo root (run for this task with
the DejaVu fallback fonts). The 22 PNGs are **bundled in `assets/og/`** here and
served from the plugin URL, so they resolve out of the box. To refresh with the
brand fonts later:

```
# put Source Serif 4 + Inter .ttf in ./fonts/, then from the repo root:
python generate-og-images.py
cp assets/og/*.png plugin/gsley-seo/assets/og/
```

## Notes / what's needed to run it

- Activate the plugin. No rewrite flush needed — `/sitemap.xml` and `/llms.txt`
  are served by intercepting the request on `init`; `robots.txt` uses the core
  `robots_txt` filter.
- Schema/meta detect the page from its URL path against the routing map, so the
  routes created by the theme's importer resolve to the right schema.
- Validate after deploy with Google's Rich Results Test and the schema.org
  validator (per the QA checklist).
- URLs use `home_url()`, so it works on any domain; the live site is
  `https://gsleydigital.com`.
